# iq-nextjs

IQ development standards for Next.js full-stack applications with Shadcn UI, Prisma, and modern React patterns.

## Included Skills

- **nextjs** - Next.js App Router patterns, server components, API routes, data fetching, and folder structure
- **design** - Shadcn UI setup, Tailwind conventions, and IQ brand guidelines
- **database** - Prisma schema conventions and database patterns
- **auth** - Authentication setup and usage patterns
- **iq-gateway** - IQ Gateway API integration and usage
- **testing** - Testing standards and practices
- **agent-browser** - Browser automation agent skill

## Installation

Add the plugin to your project's `marketplace.json`:

```json
{
  "plugins": [
    "./plugins/iq-nextjs"
  ]
}
```
