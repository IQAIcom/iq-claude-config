# iq-nestjs

IQ development standards for NestJS backend services, blockchain indexers, and WebSocket applications.

## Included Skills

- **nestjs** - NestJS architecture, folder structure, best practices, indexer patterns, and WebSocket patterns
- **database** - Prisma ORM patterns within NestJS modules, schema design, and query conventions
- **testing** - Testing NestJS services, controllers, guards, and pipes with Vitest, supertest, and Playwright

## Installation

Add the plugin to your Claude Code project by including the path to this plugin directory in your `.claude/settings.json`:

```json
{
  "plugins": [
    "plugins/iq-nestjs"
  ]
}
```
