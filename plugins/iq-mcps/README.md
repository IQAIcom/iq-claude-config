# iq-mcps

IQ conventions for building MCP (Model Context Protocol) servers.

## Included Skills

- **mcp-development** - MCP server development patterns, tool definitions, project structure, and publishing conventions based on IQ's 19 MCP server packages

## Installation

Add the plugin to your project's `marketplace.json`:

```json
{
  "plugins": [
    "./plugins/iq-mcps"
  ]
}
```
